# runmyads

Adds the Run My Ads connector (`https://app.runmyads.com/mcp/rma`, sign in with your Run My
Ads account) and the `runmyads` skill, which teaches Claude the working flow: check what is
ready with `list_capabilities`, read Ados's ideas before adding new ones, everything made is a
draft you approve in the app, and paid work shows its price first.

Install from the marketplace at the repo root:

```
/plugin marketplace add sakredapp/runmyads-plugin
/plugin install runmyads@runmyads
```
