# klipstr

Adds the connector (`https://app.runmyads.com/mcp/rma`, sign in with your account) and the
`klipstr` skill, which teaches Claude the clipping routine: find what is trending, clip it,
read each clip's grade, fix clips, post or schedule to your connected accounts, and check
results the next day. You answer the rights question for Trending videos yourself, and every
post is previewed before it goes out.

Install from the marketplace at the repo root:

```
/plugin marketplace add https://runmyads.com/claude/marketplace.json
/plugin install klipstr@runmyads
```
